# Best Sellers – Shopify Custom Section

Custom Shopify section **"Best Sellers"** built from scratch without using theme snippets.

---

## ✨ Features

- Displays up to **3 collections** via section blocks
- Each block allows:
  - Selecting a collection
  - Overriding collection title
  - Overriding product (instead of first product in collection)
- Product card shows:
  - Responsive product image using `<picture>` with `1x / 2x` density
  - Product title & price
  - Up to **3 tags** (Sale tag highlighted in red)
- Fully interactive:
  - Tabs switch products without reload
  - Wishlist popup with overlay + scroll lock
  - Add-to-cart using Shopify Ajax Cart API
- Works on desktop & mobile

---

## 📂 Files

sections/best-sellers.liquid

---

## 🛠 Installation

1. Copy `best-sellers.liquid` to your theme folder:

/sections/best-sellers.liquid

2. Open Shopify Admin → **Online Store → Themes → Customize**

3. On Home page click **Add section → Best Sellers**

4. Add up to 3 **Collection** blocks and configure them.
